# Block Party in a Box

A Day in Our Data hackathon project (Oak Park, IL, October 3, 2026). Type an Oak Park address to see whether the block can host a block party, when the petition is due, and what's on the curb.

Work in progress. The build plan is in [HANDOFF.md](HANDOFF.md). The final README will follow the event's five-heading format.

- Site (GitHub Pages): https://dsvs12.github.io/block-party-in-a-box/
- Source data: copied unchanged from [oak-park-cisc/Oak_Park_Day_in_our_Data](https://github.com/oak-park-cisc/Oak_Park_Day_in_our_Data) (`data/`, MIT License, see `source-data/LICENSE-event-repo`).

Prototype, not an official Village of Oak Park product.
